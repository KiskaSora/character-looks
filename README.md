# Внешности персонажей

Отдельная расширка для SillyTavern: теги внешности персонажа → текстовый пункт в Context Builder блока ExtBlocks.
Каталога гардероба здесь нет — только внешности.

## Если сайта нет

Сайт **не нужен**. Открой «Внешности персонажей» (меню волшебной палочки или Расширения), впиши имя и теги,
нажми «Сохранить» — внешность останется в списке «Мои внешности» (хранится в настройках SillyTavern).

- «Сохранить и в Context Builder» — сохранить и сразу отправить в блок;
- у своей внешности есть «изменить» (карандаш) и «удалить из списка» (крестик);
- изменение внешности и повторная отправка обновляют уже добавленный пункт, а не дублируют;
- удаление из списка заодно убирает её пункт из Context Builder выбранного блока.

## Если сайт есть

В Расширения → «Внешности персонажей» можно указать ссылку на сайт (поле необязательное).
Раздел «Внешности» (`wardrobe.json` → `looks`) покажется в том же окне под своими, с кнопкой обновления.

## Как работает отправка

- блок выбирается списком в шапке окна: подходит любой блок ExtBlocks с Context Builder (generated и rewrite);
  accumulation и script его не имеют, их в списке нет;
- пункт кладётся текстом (роль system) в самый низ списка, с именем персонажа в названии;
- текст собирается по шаблону (раскрывашка «Шаблон записи», сохраняется): по умолчанию
  `Как рисовать {{name}}:` → все теги внешности → `ДУБЛИРУЙ ПОЛНОСТЬЮ ВСЕ ТЕГИ ВНЕШНОСТИ ЦЕЛИКОМ.`;
  `{{name}}` — имя, `{{desc}}` — теги;
- у добавленной внешности есть «выключить» (глаз) и «убрать» (корзина).

Закрой редактор блока в ExtBlocks перед отправкой — иначе он может перезаписать изменения старой копией.

## Переезд со старого «Каталога образов»

Ссылка на сайт внешностей, выбранный блок и шаблон подхватываются из настроек старой расширки один раз.
Уже отправленные пункты в Context Builder находятся и обновляются как раньше.
Новая расширка не конфликтует со старой (свои классы `wlook-*`, свой ключ настроек).
